LOCAL SERVER REQUIRED

파일을 직접 열 수 없습니다

Relay Runner는 ES module을 사용하므로 프로젝트 루트에서 로컬 서버를 실행해야 합니다.

python3 -m http.server 4173 --bind 127.0.0.1

브라우저 주소가 file:///로 시작하면 안 되고, 실행 후 http://127.0.0.1:4173/ui/ 또는 http://127.0.0.1:4173/ui/index.html로 접속하세요.
